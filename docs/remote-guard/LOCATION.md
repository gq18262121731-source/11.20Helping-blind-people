# 定位

位置来源包括 `browser_geolocation`、`mock`，并预留 GNSS。所有者进入远程守护页后会自动请求当前电脑的浏览器定位权限；成功取得首个位置后才切换来源并写入当前设备位置记录，后续变化持续同步。位置仅在本机打开 `localhost`/`127.0.0.1` 时启用；拒绝或超时不会留下已启用的来源。切换设备、停止定位或关闭页面会停止监听，并尝试清理来源状态。若浏览器拒绝或设备无定位能力，可在守护页重试。家属能否查看仍沿用设备的位置共享与访问权限。

统一字段包括 `device_id`、`latitude`、`longitude`、`accuracy`、`speed`、`heading`、`source`、`mode`、`captured_at`、`sequence`。15 秒没有新鲜点时标记为过期，前端不再显示为实时位置。
