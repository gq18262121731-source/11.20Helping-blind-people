# 启明辅行 V2.0 架构

摄像头帧进入现有 `latest-frame` 单槽队列。YOLO + BoT-SORT 在实时检测线程消费最新帧；独立深度单槽队列按固定低频采样，Depth Anything V2 Small 在 CUDA/FP16 中运行。深度结果以 `source_id + frame_id + 图像尺寸` 关联，超过 500ms 即降级，不把旧深度伪装成当前帧。

同帧或严格时效的深度结果进入 `SpatialFusion`，得到检测框内的中位数、分位数、有效比例、质量和相对远近等级。`SpatialRiskEngine` 使用目标轨迹、关注区、框扩张率和辅助 TTC 产生内部分数。`AlertScheduler` 负责去重、升级、异步发送语音和振动；底层仍调用现有 ESP32/TTS 适配器。

前端通过现有 `/ws/web` 接收 `detection_update`、`spatial_update` 和 `obstacle_alert`。空间工作台只渲染后端实际状态，深度不可用时显示不可用。
