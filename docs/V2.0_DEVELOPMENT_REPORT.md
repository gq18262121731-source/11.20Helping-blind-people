# 启明辅行 V2.0 开发报告

## 当前状态

**PARTIAL：可运行演示版本。** 现有摄像头 → YOLO → BoT-SORT → 空间融合 → 风险评分 → 告警队列已经接入。真实 ESP32-S3 振动链路继续使用原适配器；没有连接硬件时不会伪造发送成功。

## 已完成

- 复用现有 YOLO、帧缓存、摄像头、ASR、OCR、TTS、`/ws/audio`、ESP32 适配器和前端监测页面。
- 接入官方 Depth Anything V2 Small，代码和权重自动准备并校验 SHA-256；深度线程使用最新帧单槽队列。
- 新增 `SpatialFusion`、`SpatialRiskEngine`、`AlertScheduler`，包括 ROI 统计、相对远近、跟踪框扩张、辅助 TTC、评分平滑、风险质量降级、告警去重和升级优先。
- WebSocket 新增 `spatial_update`，前端工作台显示相对深度热力图、风险原因、对象 ID/方位/深度/接近趋势和实时性能。
- 增加版本化 YAML 配置、配置校验、模型下载脚本、许可文档、部署文档、稳定性脚本和 A/B/C/D 视频脚本。
- 预警数据库为旧表增加风险等级、风险评分、触发原因和适配器投递状态；适配器收到消息不会被描述成物理振动已确认。

## 实测证据

- 环境：RTX 4060 Laptop GPU，8,188 MiB；`torchgpu` 的 PyTorch 2.6.0+cu124；CUDA 可用。
- 官方模型 smoke test：CUDA + FP16，输出与输入同尺寸 `(1362, 2048)`，有限值比例 1.0，单帧约 0.45 秒（测试图片）。
- 真实链路 smoke test：YOLO/BoT-SORT 检测、Depth Anything 同帧更新和 `spatial_update` 均收到；测试画面产生 13 个检测对象。
- Python 新增算法测试：15 passed；前端 Node 测试：68 passed；全量 Python 测试：178 passed（3 个弃用警告）。

## 未完成或受限

- 没有真实标注视频，因此误报、漏报和碰撞预警准确率为 `NOT_TESTED`；使用 `tools/run_spatial_abcd.py` 时必须提供有许可的本地视频。
- 30 分钟连续运行、真实摄像头权限和 ESP32-S3 物理振动验收为 `NOT_TESTED/BLOCKED`；使用 `tools/v2_stability.py` 可生成真实运行报告。
- 相对深度不是米制距离，内部风险分数不是碰撞概率；没有 IMU 时画面中央只是前方关注区。

## 启动

```powershell
conda activate torchgpu
python -m pip install -r backend/requirements-conda.txt
python tools/prepare_depth_model.py
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8765
```
