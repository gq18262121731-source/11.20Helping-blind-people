# V2.0 复用报告

## 已确认并复用

- `backend/services.py`：最新帧单槽队列、YOLO 推理、现有半双工语音和 ESP32 发送接口。
- `backend/camera_stream.py` / `raw_camera.py`：JPEG 校验、帧缓存、设备来源与过期机制。
- `backend/vision/tracker.py`：Ultralytics 内置 BoT-SORT，失败时按现有适配器回退 ByteTrack / predict。
- `backend/vision/spatial_analyzer.py`、`approach_detector.py`、`alert_controller.py`：既有图像空间趋势和基础告警状态机。
- `frontend/index.html` / `camera-monitor.js`：现有实时监测页面、WebSocket 和摄像头采集。
- `backend/asr.py`、`ocr.py`、`tts_protocol.py`、`/ws/audio`：原有语音、OCR、TTS 与音频接口未重写。

## 新增

- `backend/vision/depth_estimator.py`：官方 Depth Anything V2 Small 的惰性加载适配器。
- `backend/vision/spatial_fusion.py`：同帧深度 ROI 统计和相对深度等级。
- `backend/vision/risk_engine.py`：距离、关注区、跟踪框扩张和辅助 TTC 的内部风险评分。
- `backend/vision/alert_scheduler.py`：异步告警去重、升级优先、冷却和现有硬件发送适配。
- `tools/prepare_depth_model.py`：固定官方代码版本、下载权重并校验 SHA-256。
- `config/v2.yaml`、V2 文档和新增单元测试。

## 兼容性与风险

当前 `yolo-blind` 环境是 CPU PyTorch；`torchgpu` 已检测到 RTX 4060 Laptop GPU、CUDA 12.4 和 PyTorch 2.6.0。模型启动会按配置自动下载官方代码和 Small 权重；没有 GPU 或权重时，系统保留 YOLO/基础告警并明确显示深度不可用。深度值、风险分数和 TTC 均不是米制距离、碰撞概率或保证安全的承诺。
