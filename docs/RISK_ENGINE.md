# SpatialRiskEngine

初始权重为距离 0.30、关注区 0.30、运动 0.20、扩张趋势 0.20。每个目标必须使用同一 Track ID 与同一帧（或时效内）的 Depth Anything V2 相对深度；深度过期、置信度不足、没有 Track ID 或质量低于 0.35 时返回 `UNKNOWN`，不会据此发出深度风险语音。

有效评分经过三帧平滑并按阈值分级：`L0 < 0.35`，`0.35 ≤ L1 < 0.55`，`0.55 ≤ L2 < 0.75`，`L3 ≥ 0.75`。`L1` 为关注/轻度风险，`L2` 为距离较近或路径冲突风险，`L3` 为最高风险，通常需要较近、位于前方关注区和视觉扩张趋势等线索共同抬高分数。分数是内部决策指标，不表示真实距离、碰撞概率或保证安全。
